# PistaGo - Producto V1

## Problema

Los jugadores de pádel tienen que entrar en varias apps, webs o clubes para encontrar una pista libre o una partida abierta.

Esto genera pérdida de tiempo y hace difícil encontrar opciones disponibles en una zona concreta.

## Solución

PistaGo centraliza la búsqueda de pistas libres y partidas abiertas en una sola app.

El usuario podrá buscar por zona, día, hora y nivel, viendo en segundos dónde puede jugar.

## Usuario objetivo

Jugadores de pádel que quieren:

- Reservar pista rápidamente.
- Encontrar partida abierta.
- Jugar en una zona concreta.
- Comparar horarios, precios y clubes.
- Evitar revisar varias apps manualmente.

## Funcionalidades V1

### Buscador

El usuario podrá seleccionar:

- Provincia o zona.
- Fecha.
- Franja horaria.
- Nivel.
- Tipo de resultado:
  - Pista libre.
  - Partida abierta.
  - Ambas.

### Resultados

Cada resultado mostrará:

- Club.
- Hora.
- Fecha.
- Tipo.
- Nivel.
- Precio.
- Plazas disponibles.
- Plataforma origen.
- Botón para reservar o apuntarse.

### Detalle

Al pulsar en un resultado, el usuario verá más información y podrá abrir la web o app original.

## Fuentes iniciales

- La Pobla Indoor.
- Padel Interclub Meliana.

Ambos clubes usan TPC Matchpoint.

## Limitaciones V1

- No se reservará dentro de PistaGo.
- No se procesarán pagos.
- No se guardarán datos personales de jugadores.
- Se redirigirá a la plataforma original.

## Frase de producto

PistaGo: encuentra pista o partido sin entrar en mil apps.
