# PistaGo

PistaGo es una app para encontrar pistas libres y partidas abiertas de pádel cerca de ti, agrupando disponibilidad de diferentes clubes y plataformas en una sola búsqueda.

## Objetivo

Evitar que el jugador tenga que entrar en varias apps o webs para encontrar pista o partido.

## Propuesta de valor

Encuentra pista o partido sin entrar en mil apps.

## V1

La primera versión se centrará en clubes de Valencia que usen TPC Matchpoint.

## Clubes piloto

- La Pobla Indoor
- Padel Interclub Meliana

## Funcionalidades iniciales

- Buscar por zona
- Ver partidas abiertas
- Ver pistas disponibles
- Filtrar por fecha
- Filtrar por franja horaria
- Filtrar por nivel
- Ver precio
- Ver club
- Abrir enlace original para reservar o apuntarse
